# docs.tsvsheet.goldmark

Public documentation for [`tsvsheet/tsvsheet.goldmark`](https://github.com/tsvsheet/tsvsheet.goldmark) — the [goldmark](https://github.com/yuin/goldmark) extension that renders [tsvsheet](https://github.com/tsvsheet/tsvsheet) code blocks as computed tables in markdown. Published as a [Hugo](https://gohugo.io) site via GitHub Pages at [tsvsheet.github.io/docs.tsvsheet.goldmark](https://tsvsheet.github.io/docs.tsvsheet.goldmark/).
